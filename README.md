# Mainframe Hero

Fullscreen React + TypeScript + Vite + Tailwind CSS hero for Mainframe.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The hero uses the supplied CloudFront video as a fixed background. On pointer devices, horizontal mouse movement scrubs the video in either direction. The video is muted, inline, preloaded, and does not autoplay.
